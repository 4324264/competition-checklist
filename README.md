# 单项奖学金竞赛规划

郑州轻工业大学 2026 年单项奖学金认定赛事清单，328 项，按学校原表的认定顺序排列。

- 在线网页：https://4324264.github.io/competition-checklist/
- 网页里每条可搜索，点标题展开赛程节点、需要准备的材料和报名规则。
- 每条可标一个态度：计划参加、准备中、已参加、无法参加、不想参加。标过的在「已标记」里按态度分组。
- `竞赛时间与备赛清单.docx` 是同一套内容的 Word 版，18 页，适合打印。

## 关于时间

39 项写了详细赛程，其中 9 项查到 2026/2027 年官方或高校公开通知，标「核实」；
其余按往届规律推算，标「推算」。名录与级别、归口部门照抄学校原表，没有改动。
报名前请以本校教务处、校团委、就业指导中心当年通知为准。

## 重新生成

```
cd build
python data.py      # 生成 data.json
python render.py    # 生成 index.html
python make_docx.py # 生成 docx
```
